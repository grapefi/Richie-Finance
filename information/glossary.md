# Glossary

| Term | Meaning in these docs |
| --- | --- |
| CASH | Richie's algorithmic token, targeting one PDAI per token |
| RICH | Richie's fixed supply share token |
| PDAI | The PulseChain peg asset |
| PLS | PulseChain's native asset, used for gas and the PSM payment |
| Peg | A target market-price relationship; here, one PDAI per CASH |
| Expansion | Issuance of additional CASH when CASH remains above 1.01 peg over the last epoch |
| Contraction | A below-peg period in which expansion is paused and redemptions may open |
| Epoch | A 6 hour recurring interval for evaluating protocol supply policy |
| TWAP | Time-weighted average price, calculated from observations over a 6 hour period |
| PSM | Peg Stability Module; Richie's fee on RICH farm rewards, paid in PLS |
| Treasury | Protocol-owned assets and positions |
| Liquidity | Assets available to facilitate trading |
| LP position | A participant's interest in a liquidity pool, represented by the pool's supported receipt |
| POL | Protocol owned liquidity, economically owned by the treasury |
| Impermanent loss | The difference between a liquidity position's value and holding its original assets separately, due to relative price changes |
| Price impact | The effect of a trade's size on its execution price |
| Treasury rebate | A discounted option to purchase RICH tokens using Pulsechain assets funding the treasury backing |
| Vesting | The schedule under which a token payout becomes claimable |
| Buyback | A protocol-funded market purchase; it does not automatically burn the purchased tokens |
| Burn | An action that permanently removes tokens from supply under the token's rules |
| APR | An annualized rate estimate based on historic values |
